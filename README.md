NCC Attendance Report Generator
A lightweight, mobile-friendly web application deployed via GitHub Pages to streamline attendance tracking and automated report generation for NCC (National Cadet Corps) parades.

🚀 Features
Real-Time Auto-Save: Automatically saves cadet names, batch year, and attendance statuses directly to your browser's local memory. You can close the tab and return later without losing data.

Multi-Group Management: Switch between three independent tabs (Set 1, Set 2, Set 3) to manage different years or companies simultaneously.

Dynamic Visual UI: Cadet rows instantly change color based on their selected status:

🟢 Present: Green

🟡 Permission: Yellow

🟠 Late Fall-in: Orange

🔴 Absent: Red

Smart Report Generation: Instantly compiles a formatted text report, automatically excluding empty categories to keep the final output clean.

Direct WhatsApp Integration: Generate the report and send it directly to the WhatsApp app with a single tap.

Bulk Actions & Safety: Use Reset All to Present to quickly prep for a new parade day, and Clear Saved Names (protected by a confirmation prompt) to safely wipe a batch.

📱 How to Use (Mobile Setup)
For the best experience, save the live website as an app on your phone's home screen:

Open the live link in your mobile browser (Chrome or Safari).

Tap the browser's menu (three dots in Chrome, or the Share icon in Safari).

Select "Add to Home Screen".

You can now launch the attendance tracker exactly like a native app.
